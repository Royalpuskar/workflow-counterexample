      What is being proven?

      Transitions are explicit directed edges. Unsafe states are the states you forbid. Breadth-first search finds a failure with the fewest transitions, using input order to break ties. A fully explored graph with no reachable unsafe state is safe within this model.

      Depth or state limits produce an inconclusive result. Dead ends are reported separately unless listed as intentional terminal states. This checker does not infer source-code behavior, test real APIs, or prove liveness.
