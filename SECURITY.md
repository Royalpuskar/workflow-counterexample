# Security and privacy

This is a browser-local research prototype, not a production security control. It has no backend, analytics, authentication, persistence, or external runtime dependencies. Hosting providers still receive normal page requests. Inputs and exports remain under your control; do not enter credentials or personal records. User-controlled output is rendered as text.

Report reproducible bugs with synthetic data through repository issues. Do not publish real secrets. Production use needs a separate threat model, review, and integration tests.
